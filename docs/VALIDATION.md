# 验证范围 / Validation scope

The source bridge's development suite passed 121 tests before public export. The exported configuration/identity paths are tested again separately. These are regression checks, not proof of a clean install or a delivered recipient message.

Observed development checks include: new group messages reached original AstrBot/LivingMemory/DeepSeek; a background text reply produced an outgoing WeChat bubble; a DeepSeek-selected S04 was located after scrolling and produced an outgoing sticker; recent passive-image evidence reached a following directed interpretation request; controller restart with a saved run intent resumed without clearing uncertain-delivery checks.

The first S04 background attempt stopped before clicking because the title check included a right-side system notification. That was fixed and the known not-sent selection was completed once. This does not mean every sticker or a whole collection was retested after that change. A local vision description can still be semantically wrong even when the transport correctly carries it forward.

Not accepted as complete: clean second-machine install, all-group discovery, full offscreen history, complete GIF/video/voice recognition, universal layout compatibility, host reboot/unlock recovery and recipient-side network delivery for every send.

Private screenshots/logs/keys are excluded. Contributors should attach their own redacted installation receipts and actual platform versions, keeping simulated fixtures distinct from live evidence.
