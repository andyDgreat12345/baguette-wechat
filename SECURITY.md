# Security / 安全

This alpha is maintained on a best-effort basis. Please use GitHub's private vulnerability reporting feature **if enabled**; otherwise open a minimal public issue requesting a private contact route, without exploit details or secrets. Do not post credentials, private chat captures or working attacks against someone else's account.

The runtime must remain loopback-only. QR login and guest permissions are local owner actions. Group input must never grant owner/admin access. Ambiguous sends must not be retried automatically. A screen lock must never be bypassed. If a key leaks, revoke it with the provider before reporting the redacted incident.
